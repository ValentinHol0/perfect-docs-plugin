# Legal basis and sources (checked 2026-11-12)

Every legally meaningful rule in this plugin points here. Status: **verified** = read on the official page; **title verified** = article heading read on zakon.rada.gov.ua, content summarised from the code and from secondary sources; **secondary** = only commentary sites; **[Unverified]** = not confirmed — say so in the deliverable and add the verify line.

Legal and tax outputs always end with: «Перевірте з юристом / бухгалтером перед використанням: норми змінюються, а цей документ не є юридичною чи податковою консультацією.»

- ФОП group, single tax, ЄСВ, VAT registration, податкова накладна, ПРРО and receipts → **perfect-business** (`/business`, `/fop`).
