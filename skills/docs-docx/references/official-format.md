# Official-document profile (накази, листи, протоколи, довідки) — ДСТУ 4163:2020

Scope: organisational-administrative documents (ОРД) — orders, letters, minutes, memos, certificates, regulations. Not invoices, acts or contracts (those follow `docs-templates`). National standards are voluntary unless a normative act makes them mandatory (Закон «Про стандартизацію» ст. 23 ч. 2); executive bodies must follow ДСТУ 4163:2020 for paper ОРД (KMU № 55 п. 9). For businesses it is the expected professional default. Sources and status: `docs-templates/references/legal-basis.md` rows 13–15.

| Document type name (requisite 09) | bold, may be 14–16 pt, capitals or not — consistent | secondary |

Set these in the document’s styles (Normal, Title, Heading) — not by hand on each paragraph.

## 2. Requisites of ДСТУ 4163:2020 (numbers as in the standard)
Required on documents created by a legal entity: **04** Найменування юридичної особи · **09** Назва виду документа (not on letters) · **10** Дата документа · **11** Реєстраційний індекс · **19** Заголовок до тексту · **20** Текст · **22** Підпис (secondary: prokadry.com.ua).
Others used often: 02 emblem/trademark · 06 довідкові дані (address, phone, email, website, IBAN, code) · 08 код юридичної особи (ЄДРПОУ) · 13 місце складення · 15 адресат · 16 гриф затвердження · 21 відмітка про наявність додатків · 23 відбиток печатки · 24 візи · 25 гриф погодження · 26 відмітка про засвідчення копії · 27 відомості про виконавця.
Registration index parts are separated by a forward slash («01-12/345»); «м.» is omitted before Київ in requisite 13 (secondary).

## 3. Layouts
**Letter (лист)**: blank with 04, 06, 08 → date and index line «12.11.2026 № 01-12/345» → «На № … від …» (reply) → addressee block top right (organisation in nominative, position and name in dative: «Директорові ТОВ «Приклад» Петру ПЕТРЕНКУ») → heading «Про …» (no period) → text → «Додаток: … на 3 арк. в 1 прим.» → signature → executor block at the bottom left in 10–12 pt (name, phone).
**Order (наказ)**: «НАКАЗ», date and number line, place, heading «Про …», preamble (reason) → «НАКАЗУЮ:» on its own line (KMU 55 п. 89 prints the operative word «зобов’язую» in bold; emphasise «НАКАЗУЮ» the same way) → numbered points «1.», «2.» each with action, responsible person, deadline → «Контроль за виконанням наказу покласти на …» → signature → «З наказом ознайомлені:» block.
**Minutes (протокол)**: title, date, number, place → «Голова — …, Секретар — …, Присутні: …» → «ПОРЯДОК ДЕННИЙ:» numbered → for each item «1. СЛУХАЛИ: … ВИСТУПИЛИ: … ВИРІШИЛИ: …» → signatures of chair and secretary.

## 4. Electronic documents
An electronic ОРД has no personal signature line; it is signed with a qualified electronic signature (КЕП) and the signature requisite holds the position and name only (secondary: prokadry citing ДСТУ 4163:2020 п. 5.22; KMU 55 п. 119 for executive bodies). Print the visual stamp of the КЕП only if the signing service produces one.

## 5. Checks before delivery
- [ ] Margins, font, spacing set in styles; matches §1.
- [ ] Required requisites 04, 09, 10, 11, 19, 20, 22 present (09 omitted on letters).
- [ ] Date format consistent across the document; index present.
- [ ] Heading starts with «Про» for orders and letters where a heading is used; no period at the end.
- [ ] Signature block: position, line, «Власне ім’я ПРІЗВИЩЕ»; no «За»; no initials-before-surname format (that was the 2003 edition).
- [ ] Attachments listed with sheets and copies; every attachment marked «Додаток N до …».
- [ ] Every value marked [Unverified] in §1 was either confirmed by the user’s own instruction (інструкція з діловодства) or kept as the stated default.
